# Estrutura do Select

SELECT -> Seleciona aquilo que queremos consultar
FROM - > indica de qual tabela estamos puxando a informação
WHERE - > filtra por aquilo que eu quero achar em meio aos cadastros
GROUP BY - > agrupa valores que são iguais
HAVING - > Filtra os valores agrupados pelo GROUP BY
ORDER BY - > ordena os resultados de forma crescente (ASC) ou decrescente (desc)
COUNT - > conta a quantidade de registros de um determinado valor
SUM - > Soma os valores de uma determinada coluna
AVG - > tira a média de valores de uma determinada coluna
MAX - > filtra o maior valor
MIX - > retorna o menor valor

INNER JOIN - > Ligação de duas ou mais tabelas para relacionar suas informações através de colunas em comum
